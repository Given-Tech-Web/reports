# MySolar Reports System - 시스템 아키텍처

## 시스템 개요

MySolar Reports System은 3-Tier 아키텍처로 구성된 태양광 모니터링 시스템의 리포팅 대시보드입니다.

```
┌─────────────────────────────────────────────────────────────────┐
│                        전체 시스템 아키텍처                        │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│   Edge Layer          Cloud Layer           Application Layer    │
│   ┌─────────┐        ┌──────────┐          ┌───────────────┐   │
│   │Raspberry│  MQTT  │  Data    │   API    │  Next.js      │   │
│   │   Pi    │──────▶│ Collector│─────────▶│  Dashboard    │   │
│   └─────────┘        └──────────┘          └───────────────┘   │
│        │                   │                        │            │
│        ▼                   ▼                        ▼            │
│   [SQLite]           [MariaDB]               [Web Browser]       │
│                                                                   │
└─────────────────────────────────────────────────────────────────┘
```

## 데이터 흐름

### 1. 실시간 데이터 흐름
```
센서 → Edge Device → MQTT → Cloud → MariaDB → API → Dashboard
  30초     버퍼링      TLS     처리     저장    쿼리    렌더링
```

### 2. 사용자 요청 흐름
```
User Request → Next.js Router → API Route → DB Query → Response → UI Update
    HTTP          라우팅         처리        쿼리      JSON      React
```

## 재해 복구 계획

### 백업 전략
1. **코드**: Git 저장소 (일일 푸시)
2. **데이터베이스**: 일일 백업 (60일 보관)
3. **환경 설정**: 별도 보안 저장소

### 복구 절차
1. 백업에서 데이터베이스 복원
2. 코드 저장소에서 최신 버전 배포
3. 환경 변수 재설정
4. 서비스 재시작 및 검증
